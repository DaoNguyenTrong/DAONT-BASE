# Backend

Before editing anything under `backend/`, read these files in `.claude/rules/`:

- `architecture.md`
- `code-conventions.md`
- `authentication.md` when the change touches auth, sessions, tokens, cookies or API keys
- `commands.md`
- `comments.md`
- `api-contract.md` when the change touches an endpoint or DTO the frontend consumes
- `localization.md` when the change touches user-facing messages
- `testing.md`

Serena caller search and rename are valid for C# here. The repository root `AGENTS.md` still applies.

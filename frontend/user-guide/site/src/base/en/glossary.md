# Glossary

The table explains the words you meet in the app. The Vietnamese column is what the interface shows when you switch to Vietnamese.

| English            | Tiếng Việt          | Meaning                                                                                                                            |
| ------------------ | ------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Organization       | Tổ chức             | A shared workspace for a team or unit, with its own members and roles                                                              |
| Personal workspace | Không gian cá nhân  | Where you work when no organization is selected                                                                                    |
| Member             | Thành viên          | A person who belongs to an organization                                                                                            |
| Role               | Vai trò             | A set of permissions given to members, such as **Owner** or a role the organization created                                        |
| System role        | Vai trò hệ thống    | A role every organization has (**Owner**, **Admin**, **Member**), tagged **System**, which can't be edited or deleted              |
| Owner              | Chủ tổ chức (Owner) | The system role with every permission; whoever creates an organization is its Owner. An organization always has at least one Owner |
| Admin              | Admin               | The system role with the **Manage members** permission                                                                             |
| Member             | Member              | The system role with no management permissions                                                                                     |
| Permission         | Quyền               | Something you are allowed to do in an organization, such as **Manage members**                                                     |
| Slug               | Định danh           | An organization's short, unique name: lowercase letters, numbers and hyphens only                                                  |
| Inactive           | Ngưng hoạt động     | The status of an organization that was closed; its members can no longer reach it                                                  |
| Active sessions    | Phiên đăng nhập     | One sign-in on one browser or device                                                                                               |
| Remember login     | Ghi nhớ đăng nhập   | Keeps a session after the browser is closed                                                                                        |
| Verify email       | Xác minh email      | Opening the link in an email to prove the address is yours                                                                         |
| Notifications      | Thông báo           | Messages inside the app, opened from the bell                                                                                      |
| Push notifications | Thông báo đẩy       | Notifications shown on your device even while the app is closed                                                                    |
| User guide         | Hướng dẫn sử dụng   | This guide                                                                                                                         |
